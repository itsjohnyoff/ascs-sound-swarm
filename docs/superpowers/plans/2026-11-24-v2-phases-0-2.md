# v2 Phases 0 to 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Close the gap between `main` (ab93f4c) and phases 0, 1 and 2 of every agent file in the v2 task pack, so Gate 0 and Gate 1 can be run.

**Architecture:** `main` already has Agent 1 phase 0/1 transport and most of Agent 2 phases 0 to 2 (chirp detect, reference clock fit, GCC-PHAT, SRP grid + soft_l1 refine, triangle check, leave-one-out). Missing: shared chirp + golden vectors + stubs (A1 P0), event-driven live loop and v2 calibration wiring (A1 P2), the whole simulator / spike analysis / virtual swarm / benchmark (A3 P0-P2), and the whole frontend (A4 P0-P2). Fill those, reuse existing DSP, change existing code only where v2 contracts require it.

**Tech Stack:** Python 3.11+, FastAPI, numpy/scipy, pytest. Vite + vanilla TypeScript, Vitest, Canvas 2D, AudioWorklet.

**Spec:** `agent-tasks-v2/` (README, CONTRACTS, AGENT_1..4). CONTRACTS.md wins on conflicts.

## Global Constraints

- Paths per owner as in README; `shared/` changes are additive (existing DSP uses `ggwave_hybrid`, keep it in `CalibrationMode` as a deprecated value).
- Pure numpy + scipy in DSP and sim. No new Python deps. Frontend: no UI framework.
- Speed of sound from room temperature, never hardcoded.
- Mark deliberate limits with `# shortcut: <limit>, <when to upgrade>`.
- Ring buffer keeps 30 s per phone (CONTRACTS 3).
- Branch: `feat/v2-phases-0-2-sim-events-frontend`.

## Review Focus

1. A phone streams before calibration: event loop must not crash and must not emit detections.
2. The calibration chirp itself must not be reported as a clap (suppress within 0.3 s of a scheduled chirp).
3. Phone reconnects with a stale `phone_hello` position: server position wins (CONTRACTS 5).
4. A phone with a gap inside the event window is excluded, event still emitted with >= 3 phones.
5. Phone page on a non-secure context: visible warning, no silent failure.
